# Contributing to Cobblemon X Create

Thanks for your interest in the project! 💛
This repository serves as the official **Issue Tracker** for the modpack. It does not
contain the pack's files — it's where you report bugs and suggest ideas.

> ⚠️ **The modpack is in Alpha.** Our current priority is the **stability of the corepack**
> (the foundations). A **massive recipe overhaul** is planned for later, so some crafting
> imbalances are already known and expected.

---

## 🔎 Before opening an issue

1. **Check that the bug hasn't already been reported.**
   Use the [issue search](../../issues?q=is%3Aissue) — including closed issues.
   Duplicates will be closed with the `duplicate` label.

2. **Make sure you're on the latest version** available on Modrinth.
   Many bugs are already fixed in the latest build.

3. **Test on a clean installation.**
   If you added mods manually to the pack, remove them and check whether the bug persists.

---

## 🐛 How to write a good bug report

A good report saves us a lot of time. Please follow these rules:

### ✅ DO
- Use the **correct issue template** (Bug, Feature, Recipe/Progression).
- Provide a link to your **logs** via **[mclo.gs](https://mclo.gs)** (recommended) or Pastebin.
- Include the **exact version** of the modpack and of NeoForge/Forge.
- Give **clear, numbered reproduction steps**.

### ❌ DON'T
- **Don't post screenshots of your logs.** They are unreadable, uncopyable, and
  impossible to analyze. Always use an mclo.gs link.
- Don't open an issue that just says "it doesn't work" with no details.
- Don't stack multiple different bugs into one issue: **one issue = one problem**.

---

## 📂 Where to find my logs?

The `latest.log` file (and `crash-reports/` in case of a crash) is located in the
`.minecraft` folder of your instance:
- Upload the contents to **https://mclo.gs**
- Copy the generated link into your report.

---

## ⚙️ Recipes & progression

As noted above, recipes will change.
Still, please report:
- an **impossible** or **broken** recipe,
- a **softlock** (progression fully blocked),
- a recipe **conflict**.

This feedback helps us prioritize the upcoming overhaul.

---

## 💬 Need help, not reporting a bug?

For general questions or installation help, please check the
[Modrinth page](https://modrinth.com/modpack/cobblemon-x-create) first.

Thanks for helping make the pack better! 🚀
